Changelog (29/09/2026):

Display
- Extra Dim and Night Light work again.
- The default colour mode is now Saturated (vivid, native gamut) instead of the washed-out sRGB profile.
- The LiveDisplay colour profiles are removed. Settings now shows only the standard Natural / Boosted / Saturated modes, which fixes the mismatch where it showed one mode outside and another inside.

Fingerprint
- Fixed the fingerprint sensor sometimes not responding when unlocking from screen-off right after locking.

NFC
- NFC now works on global units. Older SN100 firmware rejected some settings and the NFC stack kept restarting in a loop.

Games
- Fixed the pink screen in games. Games are no longer forced onto ANGLE.

Performance and battery
- Power profile reworked for efficiency: better idle and scrolling power use, and ADPF support for smoother frame pacing.
- New lean CPU and memory tuning at boot, written for this chip only.
- Fixed a storage hang that could freeze the phone.
- Fixed a bootloop that could happen after Play system updates (APEX).

Audio
- Fixed speaker amplifier feedback.
- Disabled an unused audio plugin.

Kernel
- The ROM kernel is no longer rooted by default. For root, flash the separate KernelSU-Next (v3.4.0-legacy) or KernelSU-Next + Droidspaces kernel zip.
- Built with clang r596125.
- Storage hang fix, plus less log spam from the charger and KernelSU-Next.
